# 심사평가표 / 심사의견요약표 작성규칙 v1

> 결재본 샘플 5건(차주14·차주15·차주13·차주11·차주12, 2026.04~08 고암·율정지점)에서 추출했다.
> 계산(대출가능금액·이자수익·편중·금리)은 **검토의견서프레임워크 `calc.py`를 그대로 쓴다.** 산식을 여기서 다시 정의하지 않는다.

## 0. 원칙

- **숫자는 `sheetcalc.py`가 만든 값만 쓴다.** 손으로 더하지 않는다.
- 결재본은 **2쪽**이다. 1쪽 심사평가표, 2쪽 심사의견요약표. 두 쪽 모두 결재란이 붙는다.
- 제목은 두 쪽 모두 `□ 심사평가표   □ 심사의견요약표`로 같다(결재본도 체크 없이 인쇄된다). 체크가 필요하면 `meta.체크`에 `평가`/`요약`을 넣는다.
- 자료에 없는 값은 지어내지 않는다. 공란으로 두고 미확보 목록에 올린다.

## 1쪽 — 심사평가표

### 머리
- 결재란(계원·실장·본부장·상임이사) 우측 상단
- `( YYYY년 MM월 DD일 )`
- `신청영업점 | {지점}` / `심사담당자 | 직 | {직급} | 성명 | {성명}`
- `채무자명 | {성명} | 대출과목 | {과목} | 금액 | {원}원`
  - 채무자명·금액·신청영업점은 **파란 글씨**(결재본 관행)

### 본표 (항목 / 착안사항 / 평가내용 또는 심사의견)
항목과 착안사항은 **양식 고정**이다. 평가내용만 채운다.

| 항목 | 착안사항 | 기본값 | 비고 |
|---|---|---|---|
| 신용등급 | 신용조사 구분 | CSS면 `소호CSS평가`, 기업평가면 `기업신용평가` | 자동 |
| | 신용등급 | `CSS 1등급, NICE CB 818점(3), KCB CB 867점(2)` | **이 양식은 `NICE CB`** (검토의견서의 `NICE소호`와 다름) |
| 적법성 심사 | 법적 제한 사항(대리행위 또는 이사회의결 적정성 등) | 없음 | |
| | 업무방법 상 채무관계자 자격 | 적정 | |

| 사업계획 심사 | 사업계획 / 자금수지계획 | 적정 / 적정 | |

| 주석사항 심사 | 주석사항 확인결과 | 해당없음 | |
| 기 타 | 기타 특이사항 | (공란) | 예) `타행대환대출`, `소유권이전 대출` |

### 특인 내용 및 사유
- 특인이 없으면 `○ 특인 없음`
- 있으면 조항을 그대로 적는다. 예) `○ 여신업무방법(예) 제2편제1장제2절제3관제3조제4호에 의거 임금채권 전액 미차감`
- 특인을 적었으면 **2쪽 승인조건에 대응 서류(검토의견서 첨부)가 들어가는지** 확인한다.

## 2쪽 — 심사의견요약표

### 종합의견 (○ bullet, 순서 고정)
1. `○ 채무자 : {성명}({상호}) {조합원}, {하나로등급}` — 신규면 `신규고객`
2. `○ 우리농협 기대출 현황` + 표(대출잔액(한도)/자금용도/금리/담보구분/비고, 단위 천원·%) — 기대출 없으면 생략
   - 【확정 2026-09-16】 **6건 이상이면 자금용도가 같은 계좌끼리 묶는다.** 금액은 합산, 금리는 그 그룹의 **최대값**, 비고에 `(N건 합산)`을 붙인다.
3. `○ 대출신청금액 : {원}원({자금용도})`
4. `○ 감정가 : {원}원 ({감정일}. {감정기관})` + 다음 줄에 `({소재지})`
5. `○ 대출가능금액 : {원}원` + 산식 2줄
   - `감정가 {원}원 × {LTV}%({담보종류})`
   - `- 기대출 {원}원 - {차감명목} {원}원({비고})`
6. `○ 소요자금한도 : 매매계약 {X}백만원 × 80% = {Y}백만원` — 시설자금일 때만
7. `○ 적용금리 : {결정}% (가산 {가산}%)` + 다음 줄에 산출근거
   - `{기준}%({MOR}) +{원가}%(원가가산) -{우대}%({명목}) …`
   - **가산 = 원가가산 − 우대합계**, **결정 = 기준 + 가산**. `sheetcalc.py`가 검산한다.
8. `○ 여신업무방법(예) …` 조항들 — **받은 자료에 적힌 조항·번호를 그대로 쓴다**
9. `○ RTI산출 : {N}배` — 임대업일 때
10. 기타 확인사항(임의처분각서 징구 등)
11. `○ {연도}년 소득금액증명원 연소득 {원}원`
12. `○ {연도}년 지방세세목별과세증명서 재산세 {원}원`
13. 【확정 2026-09-16】 **낙찰통계는 넣지 않는다.** 사용자가 자료 가공 시 따로 첨부한다.

### 승인조건 및 지도사항
```
■ 실행조건
○ (조건 또는 해당없음)
■ 관리조건
○ (조건 또는 해당없음)
```
- 실행조건 예: `임금채권 미차감 검토의견서 첨부`, `매도자 채무 상환 및 근저당 설정 확인 철저`, `실거래금액 확인 철저`
- 특인(임금채권 미차감 등)이 있으면 실행조건에 검토의견서 첨부가 들어간다.

|---|---|

### 특인 3중 연결 (차주10에서 다시 확인)

### 1쪽 기타 특이사항
전결권 상향·타행대환·소유권이전처럼 **결재 라인에 영향을 주는 사정**을 짧은 명사구로: `추정임대소득 전결권 상향`.

### 전결권 상향 (사용자 설명 10-20)
RTI에 **추정임대소득**을 쓰면 전결권이 상향된다 → 그래서 심사로 올라온 건이다. 이 경우 1쪽 기타 특이사항에 `추정임대소득 전결권 상향`을 적는다.
