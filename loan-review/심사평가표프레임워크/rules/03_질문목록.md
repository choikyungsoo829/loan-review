# 작성 전 질문 프로토콜

`python scripts/sheetcalc.py cases/<건>/sheet.json --gaps`가 A~C와 검산 충돌을 뽑는다. D는 Claude가 판단해서 묻는다.
한 번에 모아서 묻고, 최대 2라운드로 끝낸다. A가 0이 될 때까지 `build.py`는 작성을 거부한다(`--draft`로만 우회).

## A. 필수 — 없으면 작성하지 않는다

| 필드 | 보통 출처 |
|---|---|
| 작성일 / 신청영업점 / 심사담당자 직·성명 | 결재 요청 화면 |
| 채무자 성명(상호) | 사전검토·여신신청서 |
| 대출과목 / 금액 / 기간 / 상환방식 | 대출조건 |
| 금리 / 기준금리 종류 / 기준금리 / 원가가산 | 금리 산출화면 — **우대내역까지 있어야 가산이 맞는지 검산된다** |
| 자금용도 구분 | 대출신청 |
| 감정가 / 담보인정비율 | 감정평가서·여신가능금액 산정 (담보대출인 경우) |
| 신용조사 구분(기업/CSS) | 신용평가 결과 |

## B. 충돌·확인 — 값은 있으나 확인한다

| 검사 | 설명 |
|---|---|
| S01 금리 산출근거 합계 ≠ 기재 금리 | 우대 하나가 빠졌거나 부호가 반대일 때 나온다 |
| S02 계산 가산 ≠ 기재 가산 | 원가가산·우대 입력 확인 |
| S03 신청금액 > 대출가능금액 | 차감내역(기대출·임차보증금·임금채권) 누락 의심 |
| S04 시설자금 > 매매금액 80% | 소요자금한도 초과 |
| C15 편중 5,000백만원 초과 | 동일인 한도 |

## C. 보완자료 — 없으면 공란 + 미확보 표시

| 칸 | 필요한 자료 |
|---|---|
| 감정가·감정일·감정기관·소재지 | 감정평가서 |
| NICE/KCB CB 점수·등급 | 신용평가 결과 화면 |
| 기대출 현황(잔액·한도·자금용도·금리·담보구분) | 여신거래 조회 |
| 연소득 | 소득금액증명원 |
| 재산세 | 지방세 세목별 과세증명 |
| RTI | 임대업 건 — RTI 산출 화면 |
| 적용 조항 | 사전검토 적법성심사·규정 발췌 |

## D. 판단 — 사용자가 정한다

| 상황 | 질문 | 기본값 |
|---|---|---|
| 특인 유무 | "특인 사항이 있나요? 없으면 '특인 없음'으로 넣습니다." | 특인 없음 |
| 승인조건 | "실행조건·관리조건에 넣을 내용이 있나요?" | 해당없음 |
| 기타 특이사항 | "타행대환·소유권이전 같은 특이사항이 있나요?" | 공란 |
| 평가내용 비표준 | 표준값(적정/해당없음/부)과 다르게 쓸 항목이 있는지 | 표준값 |

## E. 임대업(주택) 담보 운전자금 — 추가 질문 (차주10 2026-10 사례)

| 확인 | 왜 | 결재본 반영 위치 |
|---|---|---|
| 자금용도 상세 (임차보증금 반환? 매입?) | LTV 근거 문장이 달라진다(임차보증금 반환 목적 → 비규제지역 60%) | 요약표 조항 |
| RTI가 실제 임대소득인지 **추정 임대소득**인지 | 추정이면 전결권 상향 → 심사 대상이 되고 1쪽 기타 특이사항 `추정임대소득 전결권 상향` | 기타 특이사항 + 요약표 |
| 일반대출 운전자금이 5천만원 초과인가 | 초과면 자금용도 사후점검 `대상` 문구(현행 기준) | 요약표 조항 |
| 임금채권 미차감 특인 여부 | 특인·조항·실행조건 3곳 동시 | 1쪽 특인 + 2쪽 |
