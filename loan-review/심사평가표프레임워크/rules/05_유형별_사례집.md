# 유형별 사례집 — 특수 건의 규정 조합

> 기본 규칙(01~04)은 그대로 두고, **특수한 건에서 실제로 결재된 규정 조합**을 유형별로 쌓는다.
> 비슷한 건이 오면 여기서 후보를 꺼내 **사용자에게 해당 여부를 묻는다** — 자료에 근거 없이 그대로 넣지 않는다.
> 새 특수 건이 결재되면 같은 형식으로 한 절을 추가한다.

## 1. 주택임대업 · 아파트 담보 · 임차보증금 반환 목적 운전자금 (차주10, 2026-10-16 결재)

**알아보는 신호**: 개인 주택임대업자 / 아파트 담보 / 자금용도 기업운전자금인데 실제는 세입자 보증금 반환 / 국토부 임대차정보에 전세 만기 임박 / 근로소득자 겸업 / 여신신규고객

| 단계 | 결재본에 들어간 것 |
|---|---|
| LTV | 「주택관련대출 리스크 관리기준」 — 주택임대업자이나 **비규제지역 + 임차보증금 반환 목적** → 60% |
| 차감 | 소액임차 25,000,000원 (`-소액임차`) |
| 전결 | (이 건이 심사로 올라온 이유) 여신업무방법(예)별표4-2다.(2) — **RTI 추정임대소득** 활용으로 전결권 상향 (RTI 1.25배) → 1쪽 기타 특이사항 `추정임대소득 전결권 상향` |
| 한도산출 | 제4편제4장제2절제2관제4조제1항제1호 — 중소기업 5억이하 운전자금 한도산출 생략 |
| 사후점검 | 제4편제6장제2절제4관제2조 — 5천만원 초과라 사후점검 **대상** |
| 임금채권 | 제2편제1장제2절제3관제3조제4호 — 전액 미차감 (특인 + 실행조건 검토의견서 첨부) |
| 소득·세금 | 소득금액증명원(근로소득) / 지방세세목별과세증명서 재산세 |
| 첨부 | 낙찰통계(최근 1년, 아파트) 제목 줄 |

**다음 유사 건에서 물을 것**: 규제지역 여부(규제지역이면 60% 근거가 깨짐) · 반환 대상 보증금 금액/만기 · RTI 실제/추정 · 임금채권 특인 여부.
**표기**: 특수 건이라 LTV 근거를 목적까지 풀어 쓰고, LTV 괄호를 `60%(아파트임대)`로 쓰고, RTI를 전결권 조항 끝에 붙였다. 일반 건에 옮기지 않는다.
