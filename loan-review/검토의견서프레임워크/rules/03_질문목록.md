# 작성 전 질문 프로토콜

**작성(렌더링) 전에 반드시 이 절차를 거친다.** 목표는 한 번에 모아서 묻고, 최대 2라운드로 끝내는 것이다.
`python scripts/calc.py cases/<건>/case.json --gaps`가 아래 A~C 누락과 검산 충돌을 자동으로 뽑는다. D는 Claude가 판단해서 묻는다.

## 질문 방식

1. 재료를 전부 읽고 `case.json` 초안을 채운다. 각 값의 출처를 `_출처` 메모에 적는다.
2. `--gaps`를 실행한다.
3. 결과를 등급별로 묶어 **한 메시지**로 제시한다.
   - 선택지로 답할 수 있는 질문(D등급, 예/아니오)은 `AskUserQuestion`으로 묻는다. 한 번에 4개까지.
   - 값을 받아야 하는 질문(A·B·C)은 번호 목록으로 묻는다. "모름"이라고 답하면 공란으로 둔다.
4. 답을 반영하고 `--gaps`를 다시 돌린다. A등급이 0이 될 때까지 멈춘다. B·C 잔여는 `미확보 목록`으로 넘기고 진행한다.
5. 사용자가 "그냥 써" / "질문 없이"라고 하면 A등급만 묻고, 나머지는 공란으로 두고 미확보 목록에 올린 채 작성한다.

## A. 필수 — 없으면 작성하지 않는다

| 구분(신규/증액/대환/재대출/기한연기) | 사전검토 대출신청금액 칸 | "신규인가요, 증액·대환인가요?" |
| 대출금액 | 사전검토 | – |
| 증액이면 증액 전 금액 | 기존 대출현황 | "증액 대상 기존 대출이 어느 계좌(금액·금리)인가요?" |
| 금리·기준금리 종류·기준/가산 | 사전검토 대출조건 | – |

| 감정가·LTV·선순위 구성 | 여신가능금액 산정표 | – |

## B. 충돌·신뢰 낮음 — 값은 있으나 확인한다

| 검사 | 예시 (실제 샘플) |
|---|---|
| 감정기관·감정일이 자료마다 다름 | 대학로: 사전검토 '가람 25.12.' / 표B '대한' / 담보물 '태백 2025.12.03.' |
| 신용등급·소호점수가 자료마다 다름 | 차주16: KCB 702·NICE 785 ↔ NICE소호 702·KCB소호 785, CSS 4등급 ↔ 2등급 |
| 신청금액 > 대출가능금액, 총여신비율 > 100% | – |
| 시설자금 신청금액 > 매매금액 × 80% | – |
| 담보물 표 평가액 합 ≠ 감정가 | – |
| 입지현황 문장의 읍·면·동 ≠ 담보물 소재지 | 업체O: 소재지 광적면 가납리 / 입지현황 '은현면 도하리' |
| LTV상향 문구 '비거치'와 상환방식 '거치' 동시 존재 | 업체O |
| 금리 ≠ 기준 + 가산 | – |
| 금리 미기재 대출 → 금융비용 누락 (C16) | 업체O: 기업은행·서울보증 금리 '-' |
| 자료 조항이 계산상 요건 미해당 (C20) | 예: 자료엔 '30억 이상 3인심사역'인데 합계 12억 |
| 사전검토 기존대출 합계 ≠ 명세 합계 | 차주17: '1,1791,029' 오기 |

## D. 판단 — 사용자가 정한다 (AskUserQuestion)

| 상황 | 질문 | 기본값 |
|---|---|---|
| 자료에 없는 조항 후보(누락후보)가 나옴 | "자료엔 없지만 요건상 해당될 수 있습니다. 추가할까요?" (multiSelect) | 추가하지 않음 |
| 업계전망 근거 없음 | "업계전망을 일반 지식으로 쓸까요, 웹검색으로 근거를 찾을까요?" | 일반 지식 + 추정 표시 |
| 법인 임대업·PF형 | "3다에 현금흐름(DSCR) 표를 넣을까요? 넣으면 임대수입·운영경비·금융비용 가정값이 필요합니다." | 넣지 않음 |
| 주요 신용위험(사) | "주요 신용위험 섹션을 '해당없음'으로 넣을까요, 뺄까요?" | 해당없음으로 넣음 |
| 긍정/부정 사항 | 초안 2줄씩 보여주고 선택·수정 | 초안 |
| 승인조건 | 트리거로 나온 조건 목록 확인 | 트리거 결과 |
