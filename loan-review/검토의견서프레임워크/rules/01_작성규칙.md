## 0. 원칙

- **숫자는 손으로 계산하지 않는다.** 총여신비율·대출가능금액·이자수익·편중합계·금융비용은 `scripts/calc.py`가 계산한 값만 쓴다.
- **샘플 결재본을 그대로 따라 하지 않는다.** 샘플에도 복붙 오류가 있다(`05_샘플오류노트.md`). 원자료(대출사전검토의견서·증명서·감정평가서)가 기준이다.
- **재료에 없는 값을 지어내지 않는다.** 없으면 공란으로 두고 `미확보` 목록에 올린다. 추정한 값은 사용자 확인을 받는다.
- 기관명은 **회천농협**이다. 단, 3마 편중대출 고정문구 안의 "우리농협 동일인당 총대출한도"는 결재본 관행이므로 그대로 둔다.【v2】

## 신용등급 표기 (전 섹션 공통, 한 곳에서만 정의)

- 기업신용등급이 있으면 → `기업 신용등급 5C`
- CSS이면 → `CSS 4등급, NICE소호 702점(5), KCB소호 785점(4)`
  - 소호등급만 있으면 해당 등급만 적는다.
- 【v2】 적법성 첫 줄·사업체현황·종합의견 세 곳의 등급은 **반드시 같은 값**이다(차주16 샘플은 4등급/2등급으로 어긋나 있음).
- 【v2】 대출사전검토의견서의 NICE/KCB 점수는 순서가 뒤바뀌어 적혀 오는 경우가 있다 → **신용평가 결과 화면**을 기준으로 삼고, 없으면 질문한다.

## 1. 승인 신청 내역 (단위: 백만원)

- 표A: 사무소 / 구분 / 채무자 / 사업자번호 / 대출금액 / 금리(MOR종류) / 기간(상환방식) / 대출과목 / 자금용도
  - 사무소는 사전검토의견서 `발신: 회천농협 ○○지점`에서 가져온다. 표기는 `율정 / 지점`처럼 두 줄로 쓴다.
  - 【v2】 증액이면 대출금액 칸에 `400 (100 증액)`, 구분은 `신규`가 아니라 `증액`으로 쓴다.
  - 【v2】 공동대출이면 대출금액 칸에 `3,000 (총 52,000)`으로 쓴다.
- 표B: 감정가(감정기관) / 담보인정비율(담보종류) / 선순위차감액 / 기대출 / 대출가능금액 / 총여신액/가능금액 / 비고
  - 【v2】 **백만원 미만은 절사**한다(반올림 아님). 6,303.9 → 6,303, 372.7 → 372.
  - 【2026-10-20 변경】 **총여신비율 = (기대출 + 신청금액) ÷ (감정가 × 담보인정비율 − 선순위차감액) × 100, 소수 셋째 자리에서 반올림**(사용자 지정: 절사보다 보수적. 업체A 결재본 67.28%)
    - v1 산식 `(기대출+신청)/(기대출+여신가능금액)`과 수학적으로 같다. 샘플 업체J 99.45%, 업체N 99.17%는 과거 절사 관행이었으나 2026-10-20부터 반올림(99.46%/99.18%)으로 쓴다.
    - 계산은 백만원으로 자른 값이 아니라 **원 단위 원값**으로 한다.
  - 【v2】 **기대출 = 본 담보에 설정된 기존 대출**만 넣는다. 신용대출과 다른 담보 대출은 빼고, **증액 대상 기존 대출도 뺀다**(증액 후 금액이 신청금액에 들어가기 때문).
  - 【v2】 **선순위차감액 = 타 기관 선순위 설정액 + 소액임차보증금 + 차감하는 임금채권·조세채권**이다. 미차감한 임금채권은 넣지 않는다.
  - LTV 상향·하향이 있으면 둘째 줄에 `(임야, LTV상향)`처럼 적는다.
  - 주) 비고: 선순위 차감 근거와 임금채권 처리 방식을 적는다. 예) `주) 물건 전체 자가사용(주거6,상가8), 임금채권 약 280백만원(미차감)`
  - 【2026-10-20 사용자】 `주)`는 **주로 선순위채권(임금채권·임차보증금)** 설명에 쓴다. LTV 예외·대주(공동대출 동순위) 정보처럼 설명이 둘 이상이면 표 칸에 `50%주1)`·`8,000주2)`로 번호를 달고 아래에 `주1) … / 주2) …`로 나눈다(case.json `담보한도.주석`을 리스트로).

## 2. 사업체 개요

- 가. 사업체현황: 업체명 / 대표자 / 기업규모 / 업종 / 주요제품 / 기업형태 / 신용등급 / 설립일 / 주소 / 전화 / 사업자번호 / 주민·법인번호
  - 【2026-10-20 사용자】 **차주만** 쓴다. 보증인·담보제공인 현황 표는 별도 요청이 있을 때만(렌더러 `양식.담보제공인`). 소제목은 기본 `가. 나.`(원문자 `①②`는 요청 시).
  - 개인사업자는 마지막 칸 제목을 `주민등록번호`, 법인은 `법인번호`로 쓴다.
- 나. 재무현황 (단위: 백만원, %)
  - 【v2】 v1의 "항상 재무제표 없음"은 **개인사업자·신설법인에만** 해당한다. 결산 재무제표가 있는 법인은 최근 3개년(최대)을 표에 채운다(업체J·업체N 샘플).
  - 13개 열: 구분 / 총자산 / 자기자본 / 매출액 / 영업이익 / 당기순이익 / 감가상각비 / EBITDA / 금융비용 / EBITDA이자보상배율 / 부채(차입금) / 부채비율 / 유동비율
- 다. 금융거래 상황 (단위: 천원, %): 금융기관 / 대출금액 / 신용·담보 / 금리 / 비고(자금용도)
  - 대출기간 열은 재료에 기간이 하나라도 있을 때만 추가한다.
  - 비고에는 자금용도와 관계를 함께 쓴다. 예) `기업운전(증액대상)`, `가계자금(동일담보)`, `기업운전(무입보)`
  - 신규 거래처는 `회천농협 | 0 | | | 신규` 행을 둔다.
- 라. 업체전망: 사전검토의견서의 사업성 분석(긍정적 측면)과 채무자 신용 항목에서 뽑는다. 2줄 내외, ○ 기호.
- 마. 업계전망: 업종 전망 2줄 내외. 긍정 요인 1줄과 리스크 요인 1줄을 쓴다.
  - 【확인필요】 근거 자료가 재료에 없다. 일반 지식으로 쓸지 웹검색을 허용할지 사용자가 정한다(기본값: 일반 지식으로 쓰고 `추정` 표시).

## 3. 주요 항목별 검토 사항

### 가. 적법성 심사 의견
- 첫 줄: `○ 채무자 {업체표시} {신용등급}`
- 【v2·확정 2026-09-14】 **조항과 조항번호는 받은 자료(사전검토 적법성심사, 규정 발췌 등)에 적힌 것을 그대로 쓴다.** 의문이 있을 때만 그때그때 질문한다.
  - 자료에서 뽑은 조항은 `case.json 적법성.자료조항`에 `{id, 문구}`로 넣는다. 라이브러리 항목과 같은 주제면 id(L01 등)를 붙이고, 새 조항이면 id를 비운다.
  - 심사의견서 문체로 다듬는 것은 괜찮다. 예) '…부의 대상' → '…심의대상'. 조항번호는 바꾸지 않는다.
  - 라이브러리 트리거는 두 가지 용도로만 쓴다. ① 자료에 없지만 요건상 해당될 수 있는 조항을 D 질문으로 제시한다. ② 자료에 있는데 계산상 요건이 안 맞으면 B 의문(C20)을 낸다.
  - 자료에 조항이 전혀 없을 때만 라이브러리 문구로 대체해서 쓴다.
- 순서: 등급 → 대심위 → 3인심사역 → 규정 예외·특례(금리, LTV, 임금채권, 공동대출) → 사후점검
- 끝: `주) 착안사항 : 대출거래자격 및 차입행위의 제한여부, 여신규제대상 여부, 채무자의 대출의사결정상의 하자 여부`

### 나. 타당성(자금용도 및 소요자금의 적정성 등) 심사 의견
- `○ 자금용도 : {구체적 용도}` + 소요자금 조항 문구(패턴 T1~T5, 라이브러리 참조)
  - 【v2】 샘플에서 두 줄의 순서가 섞여 있다. 기본은 **자금용도를 먼저** 쓴다(v1 기준).
  - 【2026-10-28 개정】 T1은 운전자금 순여신액이 **개인(사업자) 5억원·법인 10억원 이하**일 때 쓴다(제4편제4장제2절**제2관제4조**). 순여신액 = 회천농협 기존 운전자금 + 금차이며, `calc.py`가 판정한다. ※ 종전 '제1관제5조 13억원'은 규정 개정으로 **폐지** — 과거 결재본 문구라도 쓰지 않는다.
  - 【v2】 T3(시설자금 신규)에서 매매금액의 80%가 신청금액보다 작으면 경고를 낸다.
- 끝: `주) 착안사항 : 구체적인 자금용도와 여신신청 금액은 적정한지, 소요자금이 적정한지 여부와 자금조달 계획을 참고하여 실현가능성과 자기자본과 차입금 구성의 적정성 여부`

### 다. 상환능력 등 안정성 심사 의견
- **개인사업자** 순서:
  1. `○ 상환능력 : {연도} 소득금액증명원 연소득 {원}원` (근로소득 등은 하위 줄 `- `)
  2. 부가세과세표준증명 매출액(있을 때)
  3. `○ 본건 포함 연 금융비용(차입) {원}원`
     - 【확정 2026-09-14】 **기본 = 본건 + 기존대출 전체(회천·타행, 가계 포함)의 금액 × 금리 합산.** 증액·대환 대상 기존대출은 본건으로 대체되므로 뺀다. 범위를 달리할 일이 있으면 사용자가 그때 따로 요청한다.
     - 금리가 없는 대출은 B 질문(C16)으로 묻고, 모르면 제외하고 계산한다.
  4. `○ {연도} 지방세세목별과세증명 재산세 {원}원`
  5. 기타 수익원(임대소득 등)
  6. `○ 연체·지연 이력 없음` (마지막 줄)
- **법인** 【v2】:
  - 결산이 있으면 `○ 사업체 재무분석 (단위 :백만원, %, 배, 일)` 표(매출액·차입금의존도·EBITDA이자보상배율, 3개년)에 해석 2~3줄을 붙인다.
  - 신설법인이면 `○ 신설법인으로 결산 재무제표 없어 재무분석은 제한됨.` + 부가세 매출과 연환산 + 체납이력.
  - 임대업·공동대출 PF형이면 `현금흐름 및 상환능력 검토` 표(임대수입·운영경비·금융비용·DSCR)와 지배구조를 넣는다 → 가정값은 반드시 사용자에게 받는다.
- 숫자는 원 단위로 정확히 적는다.
- 끝: `주) 착안사항 : 차입금 구성 및 만기구조의 적정성, 상환재원에 따른 상환 가능성 등 검토`

### 라. 수지기여에 대한 심사 의견
- 신규·대환: `○ 금차 대출실행 시 연간 약 {대출금액×금리}원의 이자수익 예상({금리}%)`
- 【v2】 증액: `○ 금차 증액대출 실행 시 연간 약 {증액분×금리}원의 추가 이자수익 예상({금리}%)`
- 금리 표기는 끝자리 0을 뺀다(5.20 → 5.2%).
- 끝: `주) 착안사항 : 향후 거래 전망 및 조합수지기여 정도`

### 마. 동일인에 대한 편중대출 여부 심사 의견
- 【v2】 합계 = 회천농협 기존 잔액 전체(신용·가계 포함) + 금차. 증액이면 **증액분만** 더하고, 회천농협 자체 대출을 대환하는 경우에는 대환 대상을 뺀다. 타행은 제외한다.
- 공동대출은 회천농협 참여분만 넣는다.
- `○ 금차대출 포함 총 대출금액 {X}백만원으로 우리농협 동일인당 총대출한도 {한도}백만원 이내로 적정함.` — 한도: 상호금융업감독규정 제6조⑦ — 기본 5,000백만원, **법인 조합원·법인 준조합원 10,000백만원**(자기자본 500억 이상 조합, 건설·부동산업 법인 준조합원은 제외) (calc `same_person_cap()`, 조합원 구분 없으면 C24 질문)
- 한도를 넘으면 경고하고 작성을 멈춘다. 단 HUG 등 공공기관 보증서 담보 사업비대출은 동일인 한도를 산정하지 않는다 → `07_사업비대출.md`
- 끝: `주) 착안사항 : 동일인에 대한 편중대출 여부 및 조합자기자본 규모 대비 대출금액의 적정성`

### 바. 채권보전 심사 의견
**(1) 담보물 내역({감정일}. {감정기관약칭}) (단위: ㎡, 백만원)**
- `# 소재지 : {주소} 외 N필지` → 종류 / 지목·용도 / 구조(지역) / 면적 / 평가액 / 권리사항 / 담보제공자
- 토지 지목은 대·전·답·임야·잡종지·공장용지, 건물 용도는 근생·상가·공장·창고·교육연구시설 등 감정평가 용어로 쓴다.
- 건물 면적은 소수점까지 적는다. 평가액은 백만원 절사.
- 소재지가 다른 담보가 2곳 이상이면 표를 따로 만든다.
- `- 감정평가명세표 참고 -` 행 다음에 `계` 행(면적 합, 평가액 합)을 둔다.
- 【v2】 권리사항은 `근저당 약 {X}백만원(회천농협)`, `지상권 설정(회천농협)`, 선순위 `근저당 260백만원(의정부농협)` 형식으로 쓴다.
- 【v2】 담보제공자가 제3자면 `홍길순(부)`처럼 관계를 붙인다.

**(2) 담보물 개요 및 현황** — 사전검토의견서의 도로상황·인근현황·공법상 제한 섹션에서만 뽑는다(웹검색 금지).
- ○ 입지현황 2줄 / ○ 교통상황 2줄 / ○ 공법상 제한사항 3~5개
- 【v2】 입지현황 문장 안의 읍·면·동 이름이 담보물 소재지와 같은지 `calc.py`가 검사한다(업체O 샘플은 다른 물건 문구가 복붙돼 있었음).

**(3) 평가액 산출근거**
- 【2026-10-20】 **문구는 `rules/06_문구은행.md`에서 고른다** — 감정평가서 문구 > 유형별 결재본 최빈 문구 > 기본값. 토지와 건물은 문구가 다르다(집합건물·구분건물·분양대금 기준 등 유형별 행 확인).
- 토지 기본(결재본 6건): `본 건 토지와 유사한 이용가치를 지닌 인근 및 인접 지역 내 표준지의 공시지가를 기준으로 해당 토지의 위치, 형상, 환경, 이용 상황 등 토지의 객관적 가치에 영향을 미치는 제반요인을 종합 참작하여 평가함.`
- 건물 기본(결재본 5건, 2026-10-20 원가법 → 표준단가로 교체): `대상건물과 유사한 용도, 구조 건물의 표준단가를 참작하되, 사용자재, 관리상태, 장래효용성 및 부대설비 등을 고려하여 평가함.` (원가법 문구는 문구은행 2순위, 건물 없으면 생략)
- 【v2】 감정평가서에 표준단가법 등 다른 방식이 적혀 있으면 그 문구를 우선한다(차주16·업체J·대학로 샘플).
- 【v2】 샘플의 오타 '인적지역'은 '인접 지역'으로 쓴다.

**(4) 평가액의 적정성 및 담보물의 환가성, 기타 사항 검토**
- 탁상감정 가격비교 (단위: 천원)
  - 【확정 2026-09-15】 **감정기관이 건마다 계속 바뀌므로 고정 칸을 두지 않는다.** 받은 회신만큼 칸을 만들고(기관명 그대로), 금액을 모르면 그 칸은 공란으로 둔다. 회신 자체가 없으면 표를 생략한다.

  - 【v2】 거래사례가 없고 감정평가사 의견의 지가수준만 있으면 `인근 지가수준` 표(용도지역/토지용도/도로조건/가격수준/비고)로 대체한다(업체J 샘플).
- `※ 본건 감정단가 : {X}천원/㎡({지목}) ({용도지역})`
- 기타 환가성 코멘트 ○ (가치상승 요인, 구분지상권 영향, 평가방식 혼용 등)
- 낙찰사례(인포케어, 최근1년, {물건종류}): 【v2】 샘플은 인포케어 **캡처 이미지**를 붙였다 → 캡처 파일을 받으면 이미지로 넣고, 수치만 받으면 표(경기/시/읍면동 × 1년·6개월·3개월 × 낙찰가율·낙찰률·건수)로 넣는다. 둘 다 없으면 제목만 둔다.

**(5) 보증인 내역** — `○ 대표이사 홍길동` / `○ 해당없음`

## 4. 종합심사의견
- 가. 긍정적인 사항 2줄 이내 / 나. 부정적인 사항 2줄 이내 (○)
  - 자주 쓰는 문구: `채무자 하나로 탑클래스 고객으로 농협 여신거래기여도 우수하며 연체이력 없음.` / `고액여신 거래자로 금리변동에 따른 이자비용 부담, 현금흐름 악화 가능성 있음.` / `국내·외 경기변동에 따라 사업 현황 달라질 수 있음.`
- 다. 종합 의견
  ```
  ○ 채무자 : {업체표시} {조합원여부·하나로등급(재료에 있을 때만)} {신용등급}
  ○ {목적}을 위한 {기업운전자금|기업시설자금} 요청 / {목적}을 위한 {신규|증액|대환}대출 신청
  ○ 제규정에 의한 적법성, 상환능력, 채권보전 등 검토 결과 적정
  ○ 대출예정금액 : {원}원({자금용도}[, 기존 300백만원 + 100백만원 증액])
  ○ 대출기간 : {기간} {상환방식}
  ○ 대출금리: {금리}% [(기존 가산금리 2.36%) → 당초금리 적용]
   - 기준금리 {MOR X개월} 변동 {기준}%, 예상 가산금리 {가산}% [→ 대출심사위원회 우대금리 0.57%]
   - 결정금리 상담 건으로 실행일 기준금리 변동 시 결정금리 따름
  ○ 기타 대출조건
   - (사전검토의견서 기타대출조건 + 심사과정에서 추가된 조건)
  [공동대출이면 ○ 참여 금융기관 표 + ○ 대출심사위원회 유효기간]
  ```

## 5. 승인조건 및 관리조건
- 【v2】 v1의 "기타대출조건에서 추출"은 샘플과 다르다. 샘플의 승인조건은 **트리거에서 나온다**(라이브러리 `승인조건 연동` 열).
  - 임금채권 미차감 → `○ 임금채권 미차감 검토의견서 첨부`
  - 동일인 30억원 이상 → `○ 고액여신거래자로 정기 신용평가 등 관리 철저` (신설법인이면 `신설법인·고액여신거래자로 ...`)
  - 증액 당초금리 적용 → `○ MOR금리 승인 검토의견서 첨부` 【확인필요】
  - 트리거가 없으면 `○ 해당없음`
- 나. 관리조건: 중점관리 대상이면 적고, 아니면 `○ 해당없음`
